DayFax Admin

The full admin console is the Vite React app in admin/ (email/password login). Run cd admin && npm run dev → http://127.0.0.1:5173.

Default seeded credentials (see SEED_ADMIN_EMAIL): admin@dayfax.in

Legacy static tools (fallback only):

Shops & items (legacy) Prefer the new Admin → Stores page. Search admin (legacy) Prefer the new Admin → Search page.
